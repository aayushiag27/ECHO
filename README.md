# ECHO | Music Festival

ECHO is a fictional music festival website built with HTML and CSS.

The website is designed with accessibility (A11y) in mind, following the four main accessibility principles: **Perceivable, Operable, Understandable, and Robust**.

## About the Project

ECHO works as an official festival website where users can explore the festival lineup, check the schedule, learn about the festival experience, view ticket options, and find venue information.

The main goal of the project was to create a visually engaging website while keeping it accessible and easy to navigate.

## Features

- Festival hero section with animated background
- Accessible navigation
- Artists section
- Festival schedule
- Festival experience section
- Ticket options
- Venue information
- Responsive layout
- Keyboard-friendly navigation
- Visible focus states
- Reduced-motion support
- Semantic HTML structure
- High-contrast text and backgrounds

## Accessibility

The website follows the four principles of A11y:

### Perceivable
- High contrast between text and background
- Readable typography
- Dark overlay for better text visibility
- Reduced-motion support

### Operable
- Keyboard-friendly navigation
- Visible focus indicators
- Proper links and navigation structure
- Responsive layout

### Understandable
- Clear headings
- Simple and descriptive content
- Consistent page structure
- Logical navigation flow

### Robust
- Semantic HTML5 elements
- Proper heading hierarchy
- `lang` attribute
- Accessible navigation labels
- Machine-readable `<time>` elements
- Decorative video marked with `aria-hidden`
